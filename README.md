## 固定住宅IP是什么，和动态住宅、机房IP差在哪

固定住宅IP = 住宅属性 + 地址不变。住宅IP由电信、Comcast、AT&T 这类ISP分配给家庭用户，和真实物理位置挂钩，信任度高、很难被识别成代理或机房流量；“静态”指分配之后长期归你，只要持续付费就不变。大多数家庭宽带默认是动态IP，隔几天或重启一次路由器就换，这正是很多人专门去买“固定”的原因。

市面上能买到的IP产品大致分四类，差别一眼能看出来：

| 类型 | IP来源 | 特点 | 适合 |
| --- | --- | --- | --- |
| 静态ISP代理 | ISP分配，通常托管在机房 | 固定不变、成功率高，价格偏贵 | 社媒、电商、广告验证等长期业务 |
| 动态住宅代理 | 真实家庭设备 | 池子大、匿名性强，但IP一直换 | 数据采集、价格监测 |
| 数据中心代理 | 云服务商机房 | 快、便宜，容易被识别封锁 | 不敏感的高速任务 |
| 移动代理 | 3G/4G/5G蜂窝网络 | 信任度最高，最贵也偏慢 | 移动广告验证、App测试 |

经常有人问：固定住宅IP和静态ISP代理是一回事吗？基本是。静态ISP代理就是用静态住宅IP搭建的代理服务，"ISP"这个词强调的是IP来自正规运营商，而不是机房。至于计费，动态住宅通常按流量消耗计费、适合短期需求；静态住宅按IP数量按月计费、适合长期稳定使用——这个差异下一节直接算钱。

## 买之前和拿到之后，怎么验一个固定住宅IP的质量

两步：买前问清楚，买后立刻测。

买前的功课就是上一节那四问，尤其是“家宽还是机房托管”——同样叫静态住宅IP，实际来源可能差很远。

买后用 ping0.cc 这类检测站查三样：归属地和ASN类型（住宅还是机房）、风险值、这个IP背后挂着多少人。有博主测自己在用的机场节点时发现，一个IP的共享人数上了万；换成自购的静态IP后情况完全不同。不过他也提到一个容易被忽略的现象：静态IP一样存在“抽卡”，同一商家不同批次的IP风险值有高有低，他晒出的那颗风险值在30%左右。所以到手第一件事就是测，测出来不干净直接找商家换，别拖到账号出事。

还有个细节：不同检测站的IP库更新不同步，同一个IP在不同网站可能显示不同的地区和类型。IPWO 官方FAQ的建议是拿 ipinfo 的结果当准——它更新快、数据准。两家说法打架时别急着下结论，先换工具再核一遍。

## 常见问题

**固定住宅IP和静态ISP代理是一回事吗？**
基本是。静态ISP代理就是用静态住宅IP搭建的代理服务，IP来自正规ISP而非数据中心。

**买到的IP检测出来地区不对怎么办？**
各家IP库不同步，结论会打架，先以 ipinfo 的结果为准。确认归属确实和下单不符，就找商家换。

**按流量和按IP包月到底选哪个？**
看用量。月流量4GB以下用动态池按量买，超过这个数基本就该按IP包月了。养号这种流量极低但要求IP不变的，直接包月。

**为什么换了固定IP还是被封号？**
IP只是变量之一。设备指纹、注册信息、操作行为都会触发风控。固定IP解决的是“IP不可信或频繁变动”这一项，剩下的得靠环境整体干净。
